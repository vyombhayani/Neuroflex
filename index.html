Arduino serial output example

Use this as a separate basic sensor test sketch, not a replacement for your existing servo/TFT firmware. To use your current glove sketch, add the equivalent JSON output to its loop without changing servo behavior.

// ESP32-S3: 4 flex sensors on ADC-capable GPIOs
// Raw sensor telemetry only; no servo actuation.
const int flexPins[4] = {1, 2, 4, 5};

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
  for (int i = 0; i < 4; i++) pinMode(flexPins[i], INPUT);
}

void loop() {
  int f[4];
  for (int i = 0; i < 4; i++) {
    f[i] = analogRead(flexPins[i]);
  }
  Serial.printf("{\"flex\":[%d,%d,%d,%d]}\n",
                f[0], f[1], f[2], f[3]);
  delay(100);  // approximately 10 updates per second
}

Expected serial line: {"flex":[1740,1920,1650,2010]}. The page also accepts {"index":1740,"middle":1920,"ring":1650,"little":2010}.

Before connecting

Use a proper 3.3 V sensor voltage divider with the ESP32-S3 ADC and common ground. Never apply 5 V directly to an ESP32 GPIO. Check the specific board pinout and power limits; do not power a servo from an ESP32 GPIO. For wearable testing, verify wiring and motion limits with a qualified supervisor.

If no data appears: check the selected port, USB data cable, Serial baud rate, JSON format and Arduino Serial Monitor conflict. Some ESP32-S3 boards need the appropriate USB CDC settings for Serial to appear over USB.

Privacy: Website reads serial measurements only after permission; no readings are uploaded. Session storage remains in your browser.

Project rationale

Support practice outside the clinic

Home rehabilitation may be difficult to measure consistently. A glove-based approach aims to help capture repetitions, movement patterns and trends while allowing therapists to interpret progress.

Beyond exercise counting

Track per-finger motion instead of relying only on overall repetitions.

Designed around constraints

Four sensors and a single assistive servo simplify the prototype.

Clear human feedback

Readable trends and summaries support discussion with a physiotherapist.

Research and educational prototype. Not for diagnosis, personalized therapy, or unsupervised servo-assisted treatment. A qualified clinician should set exercise ranges and targets.
